# Privacy Policy for R&D Blueprint

Effective date: September 7, 2026

R&D Blueprint is a skills-only plugin for ChatGPT and Codex. It provides instructions, reference material, and optional local scripts for creating research and software-design artifacts.

## Data handled by the plugin

R&D Blueprint does not operate an external server, require a plugin account, use analytics, set cookies, or send user content to the publisher. The publisher does not collect, store, sell, or share personal data through the plugin.

Prompts, uploaded material, generated artifacts, and tool activity are handled by the ChatGPT or Codex product and by any tools the user explicitly asks that product to use. Their handling is governed by the applicable provider policies and the user's account or workspace settings. Local scripts included with the plugin only read and write paths that the user or host environment supplies.

## External sources and links

Research workflows may ask ChatGPT or Codex to consult public sources or user-connected services. R&D Blueprint itself does not provide those connections. Any external service is governed by its own privacy policy.

## Retention and deletion

Because the publisher receives no user data through the plugin, the publisher has no plugin user records to retain or delete. Users can manage conversations, files, connected services, and plugin installation through the controls provided by ChatGPT, Codex, or their workspace administrator.

## Changes

Material changes to this policy will be published in this repository with a new effective date.

## Contact

For privacy questions, open a private-safe support request using the instructions in [SUPPORT.md](SUPPORT.md). Do not include secrets or personal data in a public GitHub issue.
