# R&D Blueprint Support

Use the public [GitHub issue tracker](https://github.com/sharthZ23/rnd-blueprint-plugin/issues) for bug reports, feature requests, installation questions, and documentation problems.

Before opening an issue:

1. Remove passwords, API keys, private repository content, personal data, and confidential research material.
2. Include the plugin version, ChatGPT or Codex surface, device or operating system, the prompt that triggered the problem when safe to share, and the observed behavior.
3. For security or privacy concerns that cannot be disclosed publicly, create a minimal issue asking the maintainer for a private reporting channel without including sensitive details.

The project is maintained on a best-effort basis. No guaranteed response time or service-level agreement is provided.
